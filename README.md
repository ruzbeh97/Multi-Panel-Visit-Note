# Multi-Panel Visit Note

A pixel-accurate recreation of the "Air" EHR visit note UI (ACL Tear physical-therapy note), built from the Figma design selected in Figma Desktop.

## Stack

- [Vite](https://vite.dev/) + [React 19](https://react.dev/) + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com/) for styling (matches the utility classes generated by the Figma design)
- [Material Symbols](https://fonts.google.com/icons) for iconography (same icon set used in the Figma file)
- [Satoshi](https://www.fontshare.com/fonts/satoshi) (body/UI copy) + [Inter](https://fonts.google.com/specimen/Inter) (nav/chrome text) via Google Fonts / Fontshare

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL (defaults to http://localhost:5173).

## Project structure

```
src/
  components/
    Sidebar.tsx          Left global navigation rail
    TopBar.tsx            Breadcrumb, Scribe/Athelas AI, global search
    PatientHeader.tsx     Patient banner, chart tabs, note metadata bar
    PanelNavBar.tsx        Right-hand vertical icon rail
    notes/
      Section.tsx          Section/sub-section heading + "Clear / Move up / Delete" action bar
      SubjectiveSection.tsx
      ObjectiveSection.tsx
      AssessmentSection.tsx
      PlanSection.tsx
      fields/              Reusable note-field primitives (text, date, radio group,
                            multi-select chips, muscle-strength table, goal card)
  App.tsx                  Overall page shell/layout
  index.css                Tailwind entry point + design tokens
```

Every field in the note (chief complaint, pain scales, muscle strength grids, goals,
multi-select chips, etc.) is a fully interactive, controlled React component backed by
local component state, so the note behaves like a real data-entry form rather than a
static mock.

## Notes on fidelity

The layout, spacing, typography, and colors were extracted directly from the Figma
file via the Figma Desktop MCP integration and translated into Tailwind utility
classes. Material icon names (e.g. `calendar_today`, `arrow_drop_down`, `delete`)
match the icon components used in the original design, rendered via the Material
Symbols web font instead of individual exported SVGs.
